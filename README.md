# Analisis Tren dan Pola Penumpang Transportasi Umum di DKI Jakarta

## Deskripsi

Project ini membahas pengolahan dan analisis data transportasi umum di DKI Jakarta untuk melihat tren serta pola jumlah penumpang. Data yang digunakan mencakup data transportasi, cuaca, dan hari libur pada periode 2023–2024. Data dari beberapa sumber diolah dan digabungkan sebelum digunakan dalam analisis dan visualisasi.

## Tujuan

* Mengolah data transportasi umum agar siap dianalisis.
* Melihat tren jumlah penumpang berdasarkan waktu dan jenis transportasi.
* Mengamati hubungan jumlah penumpang dengan kondisi cuaca dan hari libur.
* Menyajikan hasil analisis dalam bentuk visualisasi.

## Data

Data yang digunakan meliputi:

* Data penumpang transportasi umum DKI Jakarta
* Data cuaca Jakarta
* Data hari libur tahun 2023–2024
